# 寄附ギフト ダッシュボード（UIプロトタイプ）

企業の寄附 → 自治体のクーポン事業（e街） → 受け取った人の声と数字 → 企業への報告、までを画面で見るためのプロトタイプ。企業名・数字はすべて仮。

## 動かし方

```bash
npm install
npm run dev
```

http://localhost:3000 を開く。上のタブで画面を切り替え、「事例」で松本市（子育て）／さっぽろ圏（観光）を切り替える。

| 画面 | パス | 中身 |
|---|---|---|
| 受け取る人（スマホ） | `/phone` | 市の既存サイト（イメージ）→ ログイン → 登録 → クーポンを受け取る → 使う → アンケート |
| 自治体 | `/muni` | 事業ごとの利用状況・支援企業・アンケートの結果・報告書の作成・元データ・設定 |
| 寄附企業 | `/corp` | 支援している事業、届いた世帯、利用率、受け取った人の声、報告書 |
| 社内共有 | `/share` | 社員向けのページ（声がリアルタイムに届く・市のイベント） |

## 数字の流れ

```
master（設定で編集：事業・券種・寄附企業・設問・登録項目）
   +
元データ（e街の出力に似せた明細：会員・チケット・利用・加盟店・アンケート・寄附・前年度・共感）
   ↓ src/lib/derive.ts / src/lib/build-case.ts
画面の数字（自治体・企業・社内共有・報告書で同じもの）
```

- 元データは `src/data/raw/generate.ts` が決まった乱数で作る。スマホで受け取る・使う・答えると `src/data/raw/append.ts` で1行ずつ増え、全画面の数字が計算し直される。
- 自治体の「元データ」画面（`/muni/data`）で表ごとに CSV を書き出し・読み込みできる。
- 設定で寄附額を直すと、元データの寄附一覧の行が書き換わる。
- 利用率＝利用した世帯 ÷ 受け取った世帯。企業ごとの数字は、事業全体の数字を事業費に占める寄附の割合で按分。

## 確かめ

```bash
npx tsc --noEmit
npx eslint src
npx tsx scripts/verify-raw.ts    # 元データ → 数字の計算と CSV の往復
npx tsx scripts/verify-sync.ts   # スマホの操作・設定の変更が全画面の数字に反映されるか
```
