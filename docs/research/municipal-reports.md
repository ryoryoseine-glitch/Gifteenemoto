# 自治体から寄附者への報告書の実例と「型」の提案

調査日：2026-09-29
対象：企業版ふるさと納税の寄附活用報告、ふるさと納税・GCF の使い道報告、休眠預金（JANPIA）・日本財団の助成事業の報告様式

## 1. 要約

- **国は「寄附企業に成果を報告すること」を求めているが、様式は決めていない。** 内閣府の Q&A は「企業は株主や社内に説明する必要があるため、寄附企業に事業検証の結果を報告するように」とし、方法は「国において一律に定めるものではありません」としている（Q&A 第15版 A8-7）。決まった様式があるのは、事業費確定後に寄附企業へ出す「事業費の確定について」（事業名／確定した事業費／当該事業への寄附の受領額／うち貴社分）だけ。
- **自治体の実際の企業向け報告は薄い。** 兵庫県・徳之島町の例では、1事業1ページに「取組の内容・実績の件数・事業費と寄附の充当額・次年度方針・写真・担当者やトップの一言」が並ぶ程度。目標値と実績の対比は「寄附の目標額に対する実績額（達成率）」だけで、成果の目標値や事業前後の比較は載っていない。
- **前後の比較や受益者の声まで返しているのは、NPO と組んだ事業や助成事業。** 文京区こども宅食は、寄附者向けの2ページの「事業報告書」（利用前後で何ポイント上がったか、回答数 n、利用家庭の声、会計報告）と、別冊の「インパクト・レポート」（概要版45ページ＋詳細版26ページ、評価の方法、ロジックモデル、アウトカムを3段階で判定、第三者の総評）に分けている。本プロトタイプの「基本の報告書＋インパクト評価」の分け方と同じ。
- **KPI の書き方は地域再生計画の様式で決まっている。** 「KPI／現状値（計画開始時点）／目標値（計画終期）」。KPI は「できる限り実数」「アウトカムベース」「明確かつ具体的」「測定可能」「達成可能」であり、目標値は原則として現状値より改善していること。評価は「地方公共団体以外の第三者が参画した評価組織」で、毎年度行うよう努める。国への実施報告（様式第3の3）では、指標ごとに「申請時・初年度〜5年目の目標値と実績値」を書く。
- **中間と最終の違いは助成事業の様式がいちばんはっきりしている。** JANPIA では、中間は「計画どおりか・後半に何を直すか」（アウトプットの実績、短期アウトカムの進み具合、進捗を「計画より進んでいる」などで判定、事業計画の改善）、最終（事後評価）は「達成したか・価値があったか・何を学んだか」（指標の測定結果、事実と価値判断、想定外の変化、提言、知見・教訓、調査の詳細を添付）。
- **今の画面に足りないもの（詳細は第6章）：** 目標値と達成率、事業前と比べた変化（ベースライン）、地域再生計画の KPI とのつながり、中間と期末で中身が変わる仕組み（今は日付の表記しか変わらない）、期末の事業費の確定と寄附の充当、活動の写真、首長・担当課からのお礼、次年度の方針（今はインパクト評価の中だけ）、外部検証の結果、回答数 n と算定方法。

### 表から読み取れること
1. **企業版ふるさと納税の企業向け報告（#1, #2）は「使った・やった」の報告。** 事業費・寄附の充当額・件数・写真・お礼が中心で、成果の目標値や前後の比較はない。兵庫県の「達成率」は寄附の集まり具合であって、事業の成果ではない。
2. **成果まで返している例（#3, #4, #7）は、アンケートで「利用前→利用後」や「中間→事後」の値を持っている。** 回答数 n、判定の基準（50%以上なら「変化が見られた」など）、評価した人（外部の評価者・大学教員）を明記している。
3. **声の扱いは3通り。** 匿名で抜粋（#5）、属性を付けずアウトカムごとに抜粋（#4）、声は載せない（#1, #2, #6）。
4. **写真は企業版・ふるさと納税の報告ではほぼ必ずある（#1, #2, #3, #5, #6）。** 助成事業の Web 様式（#7, #8）にはない。
5. **時期。** 企業版は年度末前後（兵庫県は2月末時点で作成）〜年度終了後5か月（徳之島町）。評価報告書（#4）は期の終了から約1年後。中間の報告を寄附企業向けに出している自治体の実例は見つからなかった（**未確認**）。

### 3-3. 地域再生計画の KPI の書き方（様式）

出典：「地域再生計画 記載例（企業版ふるさと納税）」<https://www.chisou.go.jp/tiiki/tiikisaisei/kouhyou/221223_1/betten3.pdf>

- 「４ 地域再生計画の目標」の【数値目標】の表：**「5-2の①に掲げる事業（ア、イ…）／ＫＰＩ／現状値（計画開始時点）／目標値（○年度）／達成に寄与する地方版総合戦略の基本目標」**（PDF p.5）。記載例：「新規雇用創出数（累計） 0人 → 430人」「移住者数（単年度） 0人 → 35人」「合計特殊出生率 1.57 → 1.7」「町に住み続けたいと思う若年者の割合 70% → 70%」。
- KPI の要件（PDF p.6）：
  - 「できる限り実数」「アウトカムベース」「明確かつ具体的」「測定可能」「達成可能」
  - 「増加」のような目標値は不可。「目標値：350人」のように数値にする
  - 現状値は計画開始時点で把握されている値
  - 目標値は計画期間の終期の値
  - 目標値は原則として現状値より改善した数値
- 「５－２ ③ 事業の実施状況に関する客観的な指標（KPI）」：事業期間分の KPI。数値目標と同じでよい（PDF p.9）。
- 「５－２ ⑤ 事業の評価の方法（PDCAサイクル）」：記載例「毎年度○月頃に外部有識者による効果検証を行い、翌年度以降の取組方針を決定する。検証後速やかに本町公式ＷＥＢサイト上で公表する」。KPI は「地方公共団体以外の第三者が参画した評価組織」で評価を受け、毎年行うよう努める（PDF p.10）。
- 子育て事業の例示（PDF p.8）：「子育てほっとクーポンなどによる子育て支援サービスの周知・利用促進 等」。クーポン事業はこの位置づけで書ける。
- 国への実施報告（別記様式第3の3）の「4 事業の実施状況に関する客観的な指標」：**指標ごとに「申請時・初年度・2年目・3年目・4年目・5年目」の「目標値」と「実績値」**を書く表（<https://www.chisou.go.jp/tiiki/tiikisaisei/portal/pdf/sekoukisoku3_3.pdf> p.2、Q&A 第15版 PDF p.34）。

別の型（参考）：松本市の地域再生計画（地方創生推進タイプ＝交付金の計画で、企業版ふるさと納税の計画ではない）は、KPI ごとに「事業開始前（現時点）／2023年度増加分（1年目）…2027年度増加分（5年目）／KPI 増加分の累計」を書く型。評価は「毎年度」「6月」、外部委員の検証機関による（<https://www.chisou.go.jp/tiiki/tiikisaisei/dai67nintei/plan/a0247.pdf> p.2, 4）。

## 4. 助成事業の報告の様式（JANPIA・日本財団）

### 4-1. 評価の時期（JANPIA）
「資金分配団体・活動支援団体・実行団体に向けての評価指針 2024年5月改訂版」<https://www.janpia.or.jp/_assets/download/dormant-deposits/ongoing/guideline/hyoka_shishin_rev202405.pdf> PDF p.8（印刷 p.5）

| 段階 | 目的 |
|---|---|
| 事前評価 | 事業の必要性・妥当性を判断する（実施前） |
| 中間評価 | 複数年度の事業で、成果の進捗を把握し、活動や資源配分を見直す（中間地点） |
| 事後評価 | 事業終了時に、成果の達成状況や事業の妥当性を検証する |
| 追跡評価 | 必要に応じ、終了後一定期間ののちに中長期の成果・波及効果を把握する |

### 4-2. アウトプット／アウトカムの目標値と実績の書き方
- **計画時（事業計画）**：短期アウトカムとアウトプットごとに「指標／初期値・初期状態／目標値・目標状態／目標達成時期」（実例 #8：<https://johokoukai.janpia.or.jp/result/a201357/project-plan/>）。初期値がまだない場合は「事業が開始し、事前調査を行ってから初期値を設定する」と書く例もある。数値だけでなく「状態」で書いてもよい（例：「本事業を通して感想や気持ちを話すことができている」）。
- **中間評価**：アウトプットごとに「指標／中間評価時の値・状態／事後評価時の値・状態／現在の指標の達成状況／進捗状況」。進捗状況は選択式（例：「1計画より進んでいる」）。アウトカムごとに「アウトカムで捉える変化の主体／指標／中間・事後の値／これまでの活動をとおして把握している変化・改善状況」（実例 #7）。
- 中間の目標値を最初から決めていない事業もある。その場合は関係者で「事業目標が事業終了時までに達成できそうか」を議論して判断した例がある（「実行団体向け評価ハンドブック 中間評価編」<https://www.janpia.or.jp/_assets/download/dormant-deposits/ongoing/guideline/hyoka_handbook_chukan_202108.pdf> PDF p.29、印刷 p.27）。
- 指標や目標値は、必要性が認められれば中間で変えてよい（同 PDF p.14、印刷 p.12）。
- **事後評価の報告書の書き方**（「実行団体向け評価ハンドブック 事後評価編」<https://www.janpia.or.jp/_assets/download/dormant-deposits/ongoing/guideline/hyoka_handbook_jigo_202206.pdf> PDF p.20、印刷 p.18）：
  - 評価実施体制を明記する
  - アウトプット・アウトカムは、あらかじめ設定した指標の測定結果を明確に書く
  - 個別の評価は「特定した事実」と「価値判断」が分かるように書く。データの出どころを明記する
  - 提言、知見・教訓を書く
  - 調査の詳細データ（調査設計、実施方法、結果、分析）やインタビュー記録を添付する
- 記録の注意（同 PDF p.16、印刷 p.14）：「大体」「いくつかの」「半数以上が」などの抽象的な表現を避けて具体的な数字を使う。アンケートの設計や実施方法も開示する。
- 価値判断の視点（同 PDF p.17–18、印刷 p.15–16）：
  - 数字を丁寧に解釈する（参加しなかった4割の理由も見る）
  - 成果は事業によって起きたか（ほかの要因）
  - 効果は事業終了後も続くか
  - 目標値は妥当だったか
  - 外部条件の影響
  - 波及効果
  - 負の影響

### 4-3. 事業前後の比較（ベースライン）の書き方
- 事後評価ハンドブックの事例：参加申し込み時点で子どもの自己評価と親の視点で「ベースライン調査」をし、事業最終年に「エンドライン測定」をする。報告には「子どもたち全体の平均値（活動前と1年後）を示した図」を載せる（事後評価編 PDF p.24、印刷 p.22）。事前評価の段階で質問項目を作り、活動前と活動後で同じアンケートをとったことで検証が円滑になった例もある（同 PDF p.23、印刷 p.21）。
- 実例では文京区こども宅食（#3）が「こども宅食利用前／利用後」で同じ設問の割合を並べ、差を「○ポイント UP」と示している。前年の調査との比較には回答数 n を併記している（第8回 n=526、第9回 n=608）。

### 4-4. 中間と最終の違い（まとめ）

| | 中間 | 最終（事後・完了） |
|---|---|---|
| 目的 | 事業改善。計画どおりか確認し、後半の計画を直す（中間評価編 PDF p.5、印刷 p.3） | 事業成果の測定と事業の価値の判断、学びの抽出（事後評価編 PDF p.7） |

## 5. 報告書の「型」の提案

前提：
- 本プロトタイプの分け方（基本の報告書は自動で作る／インパクト評価は求められた場合だけ別冊）は、文京区こども宅食の「事業報告書（2ページ）＋インパクト・レポート（別冊）」と同じ構造なので、分け方は維持する。
- 下の型は「基本の報告書」の中間・期末。★は今の画面にない項目。
- 「自動」は消し込み・登録・アンケートから入るもの。「記入」は自治体が書くもの。

### 5-1. 中間報告（基本の報告書）— ねらい：計画どおりか、後半に何をするか

| 2 | ハイライト | 届いた世帯数／利用数／満足度（上位2つの割合）／届いた声の数。**★目標に対する進み具合（%）を添える** | 自動 | #3 p.2 |
