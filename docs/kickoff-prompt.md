# Claude Code に最初に送る指示

このフォルダで Claude Code を開き、下をそのまま送る。

---

CLAUDE.md を読んで、寄付ギフトのダッシュボードの UI プロトタイプを作ってほしい。docs/reference-prototype.html が前の HTML 版で、機能と項目はこれに揃っているけど、見た目と作りは作り直したい。

進め方：
1. まず Next.js + TypeScript + Tailwind + shadcn/ui + Recharts でプロジェクトを作り、事例（松本／さっぽろ）と役割（スマホ／自治体／企業／社内共有）を切り替える上部バーと、モックデータ（docs/reference-prototype.html の CASES を src/data/ に移す）、全画面で共有する状態を用意する。
2. 企業ダッシュボード（CLAUDE.md の ⑩）を最初に作る。Shopify 管理画面の「ストア分析」の密度と整理感が目標。できたら `npm run dev` の画面を見せて。
3. 次に自治体ダッシュボード（⑥）。複数事業の一覧を作り込む。
4. スマホの流れ（①〜⑤）、アンケート結果（⑦）、設定（⑨）、社内共有（⑪）。スマホで消し込み・回答すると、企業と自治体の画面にすぐ反映されること。
5. 最後に報告書（⑧）。基本の報告書（自動）と、インパクト評価のひな形（自治体が記入する別 PDF）を分ける。

各画面ができるたびに止めて、確認させてほしい。
